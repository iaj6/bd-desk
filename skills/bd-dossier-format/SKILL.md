# Pre-engagement dossier — output format

Write these sections, in this order. Skip one only if genuinely nothing real exists —
never pad.

Start the deliverable with the title line `# Pre-Engagement Dossier — <Company>` (the CRM
trims everything before this H1, and the eval checks for it), then:

1. **Fit score** (lead with it): **Strong / Worth a look / Skip**, one line of reasoning
   tied to the ICP in the brand canon.
2. **The angle** — the single sentence you'd open with, tailored to this company and
   drawing on the real differentiators in the brand canon. Not generic.
3. **Snapshot** — what they do, size, stage, **PE owner/sponsor if any**, regulatory
   posture. 2–3 sentences.
4. **Recent signals** (last ~6 months) — news, funding/recap, M&A/add-ons, hiring,
   audits, RFP activity, leadership change. Each with a source URL. These are timing
   wedges.
5. **Where we fit** — the specific, plausible grind the offer in the canon actually
   removes for this company. Be skeptical; if the fit is weak, say so plainly.
6. **Likely buyer** — which persona from the canon is the entry point, with a probable
   title/name if you found one.
7. **Conversation hooks** — 2–3 specific, researched openers referencing real facts you
   found (not flattery).

Grounding: cite sources inline; mark anything unverified as "unverified"; every claim
traces to something you actually found this session. The reader is a skeptical founder
with five minutes before a sales call — decision-useful over comprehensive.

After the dossier prose, emit the `<people>` block per the `bd-machine-blocks` skill.
